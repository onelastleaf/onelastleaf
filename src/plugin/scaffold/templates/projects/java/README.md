# __OLL_PLUGIN_NAME__

A Java onelastleaf plugin generated by `oll plugin new`.

The example `echo` action returns its arguments in order.

## Requirements

- JDK 21
- Gradle

## Build

```sh
gradle --no-daemon classes
```

To create a runnable distribution under `build/install`, run:

```sh
gradle --no-daemon installDist
```

## Test

```sh
gradle --no-daemon test
```

## Install with oll

Commit this project to a Git repository, then run:

```sh
oll plugin install <git-remote>
oll plugin start __OLL_PLUGIN_NAME__
oll plugin call __OLL_PLUGIN_NAME__ echo -- one two
```

Do not launch the distribution directly. oll supplies its private plugin
endpoint and manages the plugin process.
