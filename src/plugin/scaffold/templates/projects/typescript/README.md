# __OLL_PLUGIN_NAME__

A TypeScript/Node.js onelastleaf plugin generated by `oll plugin new`.

The example `echo` action returns its arguments in order.

## Requirements

- Node.js 20 or newer with npm

## Build

```sh
npm install
npm run build
```

Compiled JavaScript is written to `dist`.

## Test

```sh
npm test
```

## Install with oll

Commit this project to a Git repository, then run:

```sh
oll plugin install <git-remote>
oll plugin start __OLL_PLUGIN_NAME__
oll plugin call __OLL_PLUGIN_NAME__ echo -- one two
```

Do not run `dist/index.js` directly. oll supplies its private plugin endpoint
and manages the plugin process.
