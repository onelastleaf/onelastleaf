# __OLL_PLUGIN_NAME__

An Elixir onelastleaf plugin generated by `oll plugin new`.

The example `echo` action returns its arguments in order.

## Requirements

- Elixir 1.17 or newer with Mix

## Build

```sh
mix deps.get
mix compile
mix escript.build
```

The executable escript is written to `__OLL_PLUGIN_NAME__`.

## Test

```sh
mix test
```

## Install with oll

Commit this project to a Git repository, then run:

```sh
oll plugin install <git-remote>
oll plugin start __OLL_PLUGIN_NAME__
oll plugin call __OLL_PLUGIN_NAME__ echo -- one two
```

Do not launch the escript directly. oll supplies its private plugin endpoint
and manages the plugin process.
