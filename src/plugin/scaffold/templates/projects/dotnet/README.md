# __OLL_PLUGIN_NAME__

A C#/.NET onelastleaf plugin generated by `oll plugin new`.

The example `echo` action returns its arguments in order.

## Requirements

- .NET 10 SDK

## Build

```sh
dotnet build src/Plugin.csproj --configuration Release
```

## Test

```sh
dotnet test tests/Plugin.Tests.csproj
```

## Install with oll

Commit this project to a Git repository, then run:

```sh
oll plugin install <git-remote>
oll plugin start __OLL_PLUGIN_NAME__
oll plugin call __OLL_PLUGIN_NAME__ echo -- one two
```

Do not launch the executable directly. oll supplies its private plugin endpoint
and manages the plugin process.
