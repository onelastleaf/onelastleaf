# __OLL_PLUGIN_NAME__

A JavaScript/Node.js onelastleaf plugin generated by `oll plugin new`.

The example `echo` action returns its arguments in order.

## Requirements

- Node.js 20 or newer with npm

## Build

Install dependencies:

```sh
npm install
```

JavaScript is executed directly, so there is no separate compilation step.

## Test

```sh
npm test
```

## Install with oll

Commit this project to a Git repository, then run:

```sh
oll plugin install <git-remote>
oll plugin start __OLL_PLUGIN_NAME__
oll plugin call __OLL_PLUGIN_NAME__ echo -- one two
```

Do not run `src/index.js` directly. oll supplies its private plugin endpoint and
manages the plugin process.
