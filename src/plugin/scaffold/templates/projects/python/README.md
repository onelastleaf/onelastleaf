# __OLL_PLUGIN_NAME__

A Python onelastleaf plugin generated by `oll plugin new`.

The example `echo` action returns its arguments in order.

## Requirements

- Python 3.11 or newer

## Build

Create a virtual environment and install the project with its development
dependencies:

```sh
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
```

Python does not require a separate compilation step.

## Test

```sh
.venv/bin/python -m pytest
```

## Install with oll

Commit this project to a Git repository, then run:

```sh
oll plugin install <git-remote>
oll plugin start __OLL_PLUGIN_NAME__
oll plugin call __OLL_PLUGIN_NAME__ echo -- one two
```

Do not invoke the console script directly. oll supplies its private plugin
endpoint and manages the plugin process.
